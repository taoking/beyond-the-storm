# 验算

02《玩法》第 5 节柴粮规则的验算脚本。**不是游戏代码**，游戏实现时不沿用，只用来在设计期检查数值和动作顺序。

| 文件 | 是什么 |
|---|---|
| `02_动作级推演.py` | 半小时一步，按 02 第 5.3–5.6 节的规则逐个动作结算。02 和 03 里引用的数都以它为准 |
| `02_动作级推演_输出.txt` | 上面那份脚本用默认参数跑出来的原始输出 |
| `02_逐日推演.py` | 最早按天结算的版本，留着对照，数字不再作为依据。它允许俭的时候一天做两次檐下活计，没有炉膛和先后顺序 |

## 怎么跑

只要 Python 3，没有别的依赖。

```
python3 -B 02_动作级推演.py                # 默认每种情形 300 次 × 8 个世界年，约 20 秒
python3 -B 02_动作级推演.py --runs 50 --years 4
```

随机种子固定为 0 到 runs−1。同样的参数重跑，输出和 `02_动作级推演_输出.txt` 一致。

## 改数值

参数都在脚本开头：`WEATHER`（各季天气的机会）、`YEARS`（年份性格）、`WOOD_USE`（柴的日用度）、`P`（其余全部）。改了 02 第 5 节的任何初值，要同步改这里、重跑，更新 02 第 5.7 节、03 第 2.6 节的表和输出文件。

## 它算了什么

- 天气和年份性格；跨年时先抽新年的性格，再定新年第一天的天气；天气的连续天数边界。
- 按「够用几天」分档，每天起床时定一次。
- 备货的三条线；备柴备粮和檐下活计的时长与入库时刻；檐下活计每天各至多一次。
- 炉膛、压火、余烬、走之前添够、先取后用、冷启动；饭点。
- 做完才入库：晚上 10 点以后不开新的事，手上必需的事做完再睡。
- 菜地和暖棚；项目时间的上限。
- 出门（简化的）：每隔几天遇到能出门的天气就在早上 8 点走，三分之二下午 2 点回、三分之一傍晚 6 点回；行囊真扣库存，受「够用 3 天」的下限限制；出门前压火；上午被占了下午补活计；带回多少是参数。
- 每个世界年各个来源各得多少、檐下活计一年做几次。
- 防风林的影子存量（`belt_cap`、`belt_regen_per_year`）：只用来检查「规则之内折枯枝会不会折得比长得快」，游戏里不设这个数，取值的依据在 03 第 2.6 节。

## 它没算什么

- 一天之内天气的变化；走路和收尾的时间（算在每件事的时长里）。
- 应急燃油和罐头、食材、腌菜；俭时先吃食材。
- 菜熟了粮已装满时留在地里（脚本里是装到上限为止，多的不要）。
- 每天早上提水的半小时；读书在晚上算进度。
- 睡着时的加速（夜里一步算完）。
- 出门时在野外发生的事，只有带走多少、带回多少、几点回。

「基础修缮」在脚本里是有数值效果的四件：补窗缝（每天少烧 1 根）、搭柴棚（柴上限到 120）、整理地窖（粮上限到 90）、修篱笆（菜地每格多 1 餐）。「拓展」是暖棚和床褥窗帘（每天再少烧 1 根）。其余四件修缮不改柴粮，没有进脚本。

分年份（开局，俭的占比）：暖年 0.4%，平年 1.2%，霜早年 1.3%，春迟年 1.6%，风雪年 2.4%。

他每天的时间（平均）：

| | 活计 | 项目的上限 | 吃饭 | 其余 |
|---|---|---|---|---|
| 开局 | 2.3 小时 | 3.4 小时 | 3 小时 | 约 7 小时 |
| 基础修缮全修好 | 1.8 小时 | 3.4 小时 | 3 小时 | 约 8 小时 |
| 再加拓展 | 1.2 小时 | 3.4 小时 | 3 小时 | 约 8.5 小时 |

项目那一栏是上限：脚本假设他永远有项目可做、每天都做满。

檐下活计一年做几次：开局平均折 0.8 次枯枝、起 1 次鱼笼，99% 的年份不超过 5 次；压力情形最多 11 次；每 3 天空手出门的情形平均 2 次。防风林的影子存量（满 120 根，每年长 40 根）在规则内的各种情形里最低只到 94 根；「一整年天天暴风雪」里第 36 天见底，所以这个结构测试验的是动作顺序，不是在说最低来源能撑一整年。

## 怎么读这些结果

- 各情形里没有缺过一餐。除了被设成冷启动的那 1 小时，火没有断过。晚上 10 点没做完的事合计 0 小时。
- 「有活计的日子」是离 02 的验收线（开局不超过六成）最近的一项。
- 出门回回空手，家里会变紧：行囊带走的柴粮、出门前压的火、被占掉的上午加在一起。一趟只要带回它带走的那点柴粮，家里就不比不出门差。
- 脚本通过只说明这套规则和初值下动作顺序是闭合的。最低来源凭什么能再生，在 03 第 2.2、2.6 节；实机是否如此，要原型做出来以后用无人值守长跑重测，保存种子和最差的那几段。
