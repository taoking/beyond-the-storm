# 验算

02《玩法》第 5 节柴粮规则的验算脚本。**不是游戏代码**，游戏实现时不沿用，只用来在设计期检查数值和动作顺序。

| 文件 | 是什么 |
|---|---|
| `02_动作级推演.py` | 半小时一步，按 02 第 5.4–5.6 节的规则逐个动作结算。02 第 5.7 节的表以它为准 |
| `02_动作级推演_输出.txt` | 上面那份脚本用默认参数跑出来的原始输出 |
| `02_逐日推演.py` | v2.0 用的按天结算的版本，留着对照，数字不再作为依据 |

## 怎么跑

只要 Python 3，没有别的依赖。

```
python3 02_动作级推演.py                # 默认每种情形 300 次 × 8 个世界年，约 10 秒
python3 02_动作级推演.py --runs 50 --years 4
```

随机种子固定为 0 到 runs−1。同样的参数重跑，输出和 `02_动作级推演_输出.txt` 一致。

## 改数值

参数都在脚本开头：`WEATHER`（各季天气的机会）、`YEARS`（年份性格）、`WOOD_USE`（柴的日用度）、`P`（其余全部）。改了 02 第 5 节的任何初值，要同步改这里、重跑、更新 5.7 的表和输出文件。

## 它算了什么，没算什么

算了：天气和年份性格（跨年时先抽新年的性格，再定新年第一天的天气）、天气的连续天数边界、按「够用几天」分档、备货的三条线、备柴备粮和檐下活计的时长与入库时刻、炉膛和压火和余烬、饭点、菜地和暖棚、项目时间的上限。

在途的产出做完才入库：晚上 10 点以后不开新的事，手上必需的事做完再睡。输出里「为做完手上的事而晚睡」是这种情形的总时长。

没算：出门、一天之内天气变化、走路和收尾的时间、应急燃油和罐头、食材、睡着时的加速（夜里一步算完）。

脚本里「没有缺餐、没有无火」只说明这套规则和初值下动作顺序是闭合的。最低来源是什么、凭什么能再生，要 03 来写；实机是否如此，要原型做出来以后用无人值守长跑重测。
