# 《风雪之外》04｜UI 交互演示

> **状态：04 v1.1 UI 方向概念原型；非游戏 Demo，非美术定稿，所有数据仅用于操作演示。** 以 01 v2.7、02/03 v3.0、04 v1.1 为依据。GPT 负责 UI/交互设计与体验评估；Claude 后续负责技术实现与工程反馈。

## 如何打开

打开同目录下的 [04_桌面陪伴_交互演示.html](04_桌面陪伴_交互演示.html)，点击 GitHub 页面右上方 **Download raw file（下载原始文件）** 或 **Raw** 保存为本地 `.html` 文件，然后用 Chrome、Safari 或其他现代浏览器双击打开。

此 HTML 不引用第三方脚本、字体或图片，不需要登录、构建、启动服务器；操作和演示状态在页面内暂存，刷新后重置。

## 可以体验什么

| 操作 | 测试目标 |
|---|---|
| 打开页面 | 默认全幅木屋、克制的持续计时、九个点、当前人物行为、侧栏收起 |
| 点「任务」或「开始专注」 | 任务可选、基本计时开始/暂停、25/45/50 分钟预设 |
| 点「手记」并切换四栏 | 现实专注、世界日记、项目收藏、世界年册分离 |
| 点「镜头」 | 全景、雪窗、炉边和书桌演示；镜头不改变人物实际位置 |
| 右上角点「小窗预览」 | 雪窗默认镜头、极少 UI、独立小窗布局 |
| 点「氛围」选季节／天气／时段 | 明确显示独立氛围世界冻结；可「回到今天」 |
| 点「出门走走」 | 先看到天气、干粮、柴捆及三天家庭留存说明 |
| 确认出门，点「在野外打开专注」 | 冻结户外，显示空木屋；再次点「返回野外」回到原地点 |
| 页脚点「模拟一件真实世界事件」 | 切换人物示例动作并在世界日记加入演示记录 |
| 页脚点「演示获得一份」 | 九个点发生低存在感变化；不连接真实奖励与存档 |

## 与正式游戏的边界

1. SVG 木屋与雪林仅作为**信息层级和氛围示意**，不是 05 的正式 16-bit 像素游戏资产。
2. 计时按钮实际进行本地页面内倒计时，但**没有实现** 02 的跨日存储、10 分钟有效时间统计、45 分钟份数冷却或异常休眠恢复。九个点是**演示数值**。
3. 不能通过点击示意事件、返家按钮或份数按钮产生正式世界时间、资源与项目进度。出门“模拟走到家门口并返家”只为验证 UI 状态，不是正式游戏的瞬移功能。
4. 场景季节的美术变化与三张野外地图尚未绘制，面板能测试的是**状态切换**，不是游戏世界已运行。
5. 不验证 Web 浏览器是否可系统级置顶、不抢外部编辑器焦点或真实后台休眠；这些留 06 工程验证。
6. 不把专注 UI、奖励或样式与木屋生存绑定；没有强制每日任务或临时操作角色生活的按钮。
