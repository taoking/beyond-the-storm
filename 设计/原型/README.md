## 可以体验什么

| 操作 | 测试目标 |
|---|---|
| 打开页面 | 默认全幅木屋、克制的持续计时、九个点、当前人物行为、侧栏收起 |
| 点「任务」或「开始专注」 | 任务可选、基本计时开始/暂停、25/45/50 分钟预设 |
| 点「手记」并切换四栏 | 现实专注、世界日记、项目收藏、世界年册分离 |
| 点「镜头」 | 全景、雪窗、炉边和书桌演示；镜头不改变人物实际位置 |
| 右上角点「小窗预览」 | 默认雪窗、可点小窗内的「切换镜头」改为炉边、展开完整窗后恢复原来全景，隐藏具体任务名 |
| 点「氛围」选季节／天气／时段 | 明确显示独立氛围世界冻结；可「回到今天」 |
| 点「出门走走」 | 先看到天气、干粮、柴捆及三天家庭留存说明 |
| 确认出门，点「在野外打开专注」 | 冻结户外，显示空木屋；再次点「返回野外」回到原地点 |
| 点击炉火、柴堆、书桌、书架、窗台玻璃罐 | 打开状态／手记详情，不能强制角色添柴或做饭；支持键盘聚焦打开 |
| 页脚点「模拟一件真实世界事件」 | 切换人物生活动作，场景出现/消失一件生活痕迹，并在世界日记加入演示记录；同时整理待放的小球果 |
| 页脚点「演示获得一份」 | 九个点立即更新，但玻璃罐暂不多出小球果；直到模拟人物有空整理才反映到场景 |

## 与正式游戏的边界

1. SVG 木屋与雪林仅作为**信息层级和氛围示意**，不是 05 的正式 16-bit 像素游戏资产。
2. 计时按钮实际进行本地页面内倒计时，但**没有实现** 02 的跨日存储、10 分钟有效时间统计、45 分钟份数冷却或异常休眠恢复。九个点是**演示数值**。
3. 不能通过点击示意事件、返家按钮或份数按钮产生正式世界时间、资源与项目进度。出门“模拟走到家门口并返家”只为验证 UI 状态，**不代表正式游戏可以点按钮瞬移返家**。
4. 场景使用 SVG 示意，季节/时段的轻量滤镜与窗外飘雪仅验证氛围层次；三张真正可探索的野外地图和完整四季美术尚未制作。窗外/户外可见雪，室内不出现装饰性飘雪。
5. 不验证 Web 浏览器是否可系统级置顶、不抢外部编辑器焦点或真实后台休眠；这些留 06 工程验证。
6. 不把专注 UI、奖励或样式与木屋生存绑定；没有强制每日任务或临时操作角色生活的按钮。

## 本轮 v1.2 重点

UI 主目标仍是「在电脑写代码时，画面安静；抬头时，木屋像真的有生活」。本轮优化控制栏的存在感、木屋可点击区域、小窗镜头/返回入口、环境动效的位置，以及份数先记账后由角色整理的演示顺序。具体说明见主规范 04 §17。
