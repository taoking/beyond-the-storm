## 与正式游戏的边界

1. SVG 木屋与雪林仅作为**信息层级和氛围示意**，不是 05 的正式 16-bit 像素游戏资产。
2. 计时按钮实际进行本地页面内倒计时，但**没有实现** 02 的跨日存储、10 分钟有效时间统计、45 分钟份数冷却或异常休眠恢复。九个点是**演示数值**。
3. 不能通过点击示意事件、返家按钮或份数按钮产生正式世界时间、资源与项目进度。出门“模拟走到家门口并返家”只为验证 UI 状态，**不代表正式游戏可以点按钮瞬移返家**。
4. 场景使用 SVG 示意，季节/时段的轻量滤镜与窗外飘雪仅验证氛围层次；三张真正可探索的野外地图和完整四季美术尚未制作。窗外/户外可见雪，室内不出现装饰性飘雪。
5. 不验证 Web 浏览器是否可系统级置顶、不抢外部编辑器焦点或真实后台休眠；这些留 06 工程验证。
6. 不把专注 UI、奖励或样式与木屋生存绑定；没有强制每日任务或临时操作角色生活的按钮。
