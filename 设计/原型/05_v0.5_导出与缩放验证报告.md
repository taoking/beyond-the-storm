## 3. Clone 项目后运行

安装：python3 -m pip install lxml cairosvg pillow

自检：python3 设计/原型/05_v0.5_图层导出自检.py

导出：

    python3 设计/原型/05_v0.5_透明图层导出.py \
      --svg 设计/原型/05_雪夜木屋_高保真分层母场景_v0.4.svg \
      --out .art-v0.5-layers --scale 2 --trim

生成内容：

- NN_图层名.png：**960×540** 的 RGBA 透明全画布图层（按 2 倍最近邻）。
- NN_图层名.trim.png：自动去透明空白的裁剪图；manifest.json 里保留原坐标锚点。
- source_preview.png 与 recomposed_preview.png：用于图层合成精确性比较。差异过大时应先修导出逻辑，不得“修正世界事实”。
- window_*.png 与 hearth_*.png：旧裁切与整数候选的图像对比。

## 4. 小窗像素缩放的真实取舍

480×270 逻辑母图放进 320×180 为 2/3 倍，放进 1280×720 全景为 8/3 倍。即使用最近邻，像素块宽度也可能不均。原雪窗 228×128 裁切投到两种小窗尺寸也不是整数倍。

| 目标窗口 | 原雪窗裁切 | v0.5 整数候选 | 目前判断 |
|---|---|---|---|
| 320×180 | [41,98,228,128] 非整数 | [0,52,320,180] 原生 1× | 像素稳定但场景更广、人物更小，需实测陪伴感 |
| 480×270 | 原雪窗非整数 | [35,94,240,135] **2×** | **优先测试**，窗、罐、人物仍应在镜头中 |
| 1280×720 | 全景 [0,0,480,270] 非整数 | 部分特写可以取 320×180 后 4×，全景不足 | **暂不拍板**，需优先保护完整全景构图 |

**像素整数缩放不是唯一目标。** 如果 320 的 1× 远景里角色不可辨认，不能为了技术洁癖强制采用它；更不能修改角色真实作息来保证镜头有观众。

## 5. 与 Claude 06 的真实状态边界

- actor_indoor 和 hi_fi_knit_detail 导出为两层后仍须**同显同隐**，不能出现“幽灵毛衣”。
- jar_state 与 jar_fill_example 由**角色真正整理后的球果**驱动，而不是专注刚得份就立刻给罐子增加内容。
- woodpile 只读真实柴堆库存档位；雪粒只显示窗外真实天气或独立氛围预览。
- hi_fi_station_props 等组仍混有多个物件，某些设施可能未修好或装饰尚未解锁，**不能把这些整体 PNG 直接当作正式全部可见的物件**；下一阶段还需二次拆层。
- far_worker_optional 继续默认隐藏；必须依据真实近院人物位置与可见率决定是否启用。
