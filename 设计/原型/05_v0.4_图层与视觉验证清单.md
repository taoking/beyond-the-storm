## 2. 资产与层级

| 分组 | SVG group ID | 是否应由 06 驱动 |
|---|---|---|
| 基础墙板 | `interior_base`, `hi_fi_wood_grain` | 不需要 |
| 冬季窗外 | `window_weather`, `hi_fi_snowflakes`, `hi_fi_window_frost` | 真实季节天气或冻结氛围预览 |
| 窗框和家具 | `window_frame`, `static_furniture` | 修缮变更须使用独立状态层 |
| 气象站器具与小物 | `hi_fi_station_props`, `desk_objects` | 真实动作、项目和已拥有样式；不假装初始已解锁 |
| 玻璃罐 | `jar_state`, `jar_fill_example` | 现实得份先记录，人物整理后更新填充 |
| 地面织物 | `hi_fi_floor_fabrics` | 当前静态场景试片；正式使用需核对 03 装饰状态 |
| 室内人物 | `actor_indoor`, `hi_fi_knit_detail` | **两层绑定同一个 actorVisibility**，不要出现“幽灵毛衣” |
| 炉膛 | `stove_fire`, `hi_fi_light_pixels` | 由真实炉火五态决定；冻结演出不扣木柴 |
| 灯光 | `lighting_overlay` | 根据真实时段和照明状态 |
| A4 院外远景候选 | `far_worker_optional` | 默认隐藏，需真实近院位置与构图验收 |

所有层仍共用一个 480×270 逻辑坐标，不允许每个镜头再造一间“不同摆设的屋子”。书桌在雪窗下，室内人物穿毛衣便服，窗外雪粒必须由 clipPath 限制，**不能让雪飘进木屋**。

[自动截图验收脚本](05_v0.4_浏览器截图验收.py) 已提交，可在有 Playwright 和 Chromium/WebKit 的本地环境运行；**尚未实际运行**。

## 3. 视觉上必须实际检查的用例

- [ ] **全景 1280×720**：窗外、桌前人物、炉火同框；远处仪器不与主角争焦点。
- [ ] **雪窗 320×180**：雪/罐/书桌/人物头肩与手部同时可见；边缘状态与专注计时不遮蔽核心动作。
- [ ] **雪窗 480×270**：人物空镜时仍有真实天气和场景生活痕迹；不自动追人。
- [ ] **炉边 320×180/480×270**：炉火焰和水壶可辨，暖光不会覆盖 UI 数字。
- [ ] **有人/无人切换**：隐藏人物时同时隐藏毛衣纹理；不会出现残影/单独手臂。
- [ ] **减动态效果**：后续 Web/Mac 动画试验应满足系统偏好，静态画也能读懂天气/炉火状态。
- [ ] **世界冻结**：切季节/天气只能变演出，不推进真实世界物资、项目或写日志。
- [ ] **像素缩放策略**：480×270 母场景到 320×180、1280×720 有**非整数倍**，雪窗 crop 到某些尺寸也不是整数倍。当前采用 nearest-neighbor 预览，仍需在 06 确定是接受不均匀像素、重新选择统一逻辑尺寸，还是对不同视图独立像素合成/留边。**尚不能称为三种尺寸完全 pixel-perfect**。
- [ ] **SVG → 正式精灵**：层 ID 和遮挡关系可转成真实透明 PNG/图集；各个真实修缮状态、天气和动作过渡帧仍需单独产出。
- [ ] **音频**：根据 05 的声音规范录制/选取无打扰的风、炉火、翻书与壶声；当前演示无音频，不表示自动得到授权素材。

## 4. 验收信息与 Claude 06 对齐

建议 Claude 提供带时间戳或模拟种子的真实角色时间分布：桌前阅读/记录、近院可见、去泉屋/林边不可见、炉边休息及睡眠；以及 2–4 小时陪伴期中真实生成的可见事件与内容。这些结果决定镜头切法与场景资产量，**不反向修改角色日程去满足“画面必须有人”**。

GPT 接下来优先完成：真实浏览器截图和裁切检查 → 服装、脸部、书本与杯子细化 → 冬季母场景与可变层拆成可交付的透明素材 → 角色基础动作帧复用。**不启动额外宠物、资源条、剧情系统或第二套 UI**。
