## 实际完成与重要限制

- 四张图片已作为 **真正 Git 二进制 Blob** 上传，不是 README 中的占位路径。每张 2560×1440 WebP 经过 SHA 校验。
- **这些仍属高细节 LOOKDEV/视觉展示，不是通过 G5 的正式母图**：AI 原图为 1672×941，裁成正 16:9 后再平滑扩到 2560×1440；不能称为“原生 2560×1440 绘制”。
- 炉间目前相对接近空屋，但窗外、材料和可变家具仍是烘焙。其他三间的男主人公与灯光已画进图中。卧室人坐在床上，并非正式指定的被中睡姿。
- **G5 要求的全部独立分层还没做**：窗玻璃透明孔、窗外独立天气、夜色/油灯/炉火光、状态家具/物品、正式演员 sprite、接触阴影/遮挡。
- 灶间已出现可能被误解成第二火炉的炉具（03 规定只有炉间一处火），作为 G5 复画要改；角色身份各图尚需统一。
- 这批画不直接放进 `assets/05/` 的“正式成品”，避免 Claude 误用为开局中性素材。

## 接下来的制作闸门

1. 用户看四间效果，确认大窗、家具和门的视觉取舍。
2. 在已有场景上重绘 **真正的原生 2560×1440 中性空屋**；不能以当前上采样 WebP 充当原生。
3. 窗外、天气、火、光、人物、道具分层并与 `Snapshot` 字段逐一绑定。
4. Claude 按[原型站位](../05_木屋四间_20261115/站位与房间.json)重标正式真实锚点，并验证 320×180、480×270、1280×720 渲染。
