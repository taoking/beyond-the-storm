# 出图工具对比单（Gemini 和 ChatGPT）

> 给用户。两个工具各出两张，放回 `出图/对比/`，Claude 量过定用哪个（HANDOFF 第 3 节 D-5）。`出图/` 不入库。

## 准备

底图：`出图/对比/炉间底图.png`（2560×1440，就是现在的炉间，空屋、炉子没生火）。工具传不上大图就用 `炉间底图_小.png`（1600×900）。

两个工具都用各自最好的出图模型；有分辨率选项的选最大、比例选 16:9。

## 第 1 张：局部重绘（最要紧）

上传底图，发：

> 在这张图里加一堆码好的劈柴：放在柴炉右边、石台旁的地板上，大约到人的膝盖高，看得见木头端面的年轮和树皮。光线、透视、笔触和原图一致。除此以外**图上任何东西都不要改**：构图、家具、窗户、窗外、颜色都保持原样，输出和原图一样大小。

存成 `gemini_1.png`、`chatgpt_1.png`。

## 第 2 张：直接出高分辨率底图

上传底图，发：

> 照这张图重新画同一间屋子：同样的构图、家具和位置，同样的手绘插画风格。屋里没有人，柴炉不生火，**窗外不下雪**（晴天，天空和雪地干净）。比例 16:9，分辨率尽可能高（至少 2560×1440）。

存成 `gemini_2.png`、`chatgpt_2.png`。

## 注意

- 下载原图，不要截屏。
- 一张出得不好可以重出，但每个工具最多出三次，把最好的一张放回来；顺便告诉我各重出了几次。

## Claude 量什么

| | 看什么 |
|---|---|
| 第 1 张 | 柴堆以外的地方变了多少（跟底图逐像素比）；柴堆跟底图的光线、笔触合不合；尺寸对不对 |
| 第 2 张 | 实际分辨率；构图、家具位置跟原图差多少（能不能沿用 `room_locations.json`）；窗外是不是真没雪；细节在 2560 下糊不糊 |

第 1 张决定能不能用「局部重绘再抠层」做道具，第 2 张决定能不能出原生的正式底图。

## 结果（2026-11-16，Claude 量的）

| | Gemini | ChatGPT |
|---|---|---|
| 第 1 张尺寸 | 2728×1536 | 1672×941（传进去 2560 的图，出来还是这个尺寸） |
| 第 1 张：加柴以外变了多少（放到 2560 比，PSNR，越高越像原图） | 左半 26.7 dB、上部 30.0 dB | 左半 29.6 dB、上部 31.5 dB |
| 第 1 张：位置对不对得上 | 对得上，差别只在纹理上，没有整体挪位 | 同左 |
| 第 1 张：柴堆 | 像手绘，光线对；但比要的大，压出石台、挨到门框 | 规矩，放在石台上、高度对；略像图库素材 |
| 第 2 张尺寸 | 2752×1536 | 1672×941 |
| 第 2 张：放到 2560 看 | 清楚，笔触细 | 是放大的，偏软；颜色更艳、光更硬 |
| 第 2 张：构图 | 跟原图接近，但家具位置有挪动（PSNR 17.6 dB），站位要重标 | 同样有挪动（17.2 dB） |
| 第 2 张：窗外 | 晴天，没有雪粒 | 晴天，没有雪粒 |

- 两个工具改图时都会把整张重画一遍（纹理有细小差别），但位置对得上。所以做道具时按柴堆这一块的范围抠，范围以外照旧用底图，不受影响。
- ChatGPT 出不了比 1672×941 更大的 16:9 图，正式底图要放大，等于回到现在这套的老问题。Gemini 直接出 2.7K，裁成 2560×1440 就是原生的。
