# 野外按动作走：实现、待定的做法、02 改动草案（Claude）

> 2026-11-14，分支 `claude/06-outdoor-actions`。用户 2026-11-14 定「野外的时间按动作走」，06 v0.4（GPT 的松林竖切）不合并、由 Claude 重做。本篇记三件事：做成了什么；02 没写死、我先选了一种做的（第 2 节，等用户定）；02 要跟着改的七处文字（第 3 节，**用户点头以后再改 02**）。

## 1. 做成了什么

点门出门 → 去松林（路上 20 个游戏分钟）→ 在 15×9 的地图上走、采、歇、吃干粮、生火 → 走回林口 → 回家入库。站着不动世界不走。

- **一个时钟。** 户外直控时 `worldRate` 是 0，现实时间一点也不推世界。所有花时间的动作（走一格、自动走过去、采、歇、吃、生火、区域和家之间的路）每一分钟都从 `outing.ts` 的 `outdoorMinute` 过：家里走一分钟（他不在家，只有炉火在烧）、饭点吃干粮、身体按这一分钟在做的事变化、看要不要昏倒、要不要提一句回家。v0.4 那个绕开返家提示的 `spend()` 没有了。
- **身体状态在 `OutingState.body`**：体温、体力、生命，0–10000 的整数，界面显示成 0–100。出门时都是满的，所有区域通用。
- **区域是数据。** `content.ts` 的 `AREAS`：地图、入口、回家出口、生火点、资源点。`wild.ts` 是读它的通用规则，`outing.ts` 不引用 `wild.ts`。溪谷、冰湖以后加数据就行（区域之间的路等那时再加）。
- **工棚按 03 第 3.4 节的账**：木料 10、旧绳索 3、帆布 5、1 罐油、1 个罐头。种子、书、胶卷、旧工具内核还没有，没放。
- **一套命令**：`cmdOutdoor(g, wall, action)`，动作有 `move / walkTo / gather / rest / eat / fire / travel`。旧的 `cmdTravelTo`、`cmdHeadHome` 并进来了，旧测试迁了过去。
- **数值全在 `config.ts`**：02 写了的（背包 20 格、各样堆叠）在 `CONFIG.outing`；实现补的在 `IMPL.wild`。昏倒丢多少仍是 `IMPL.collapseLossRatio`。
- **昏倒的手记按原因写**：冻的「在外面冻得撑不住了」、累的「在外面累得走不动了」、午夜「夜里在外面撑不住了」。
- **灰盒界面**：野外一栏单独放（`#wild`），内容变了才重画，按钮不会在按下和松开之间被换掉；检查面板鼠标停着不重画的做法没动。WASD／方向键走一格，按住时一步至少隔 200 毫秒；点地图上的格子自动走过去。
- **存档**：老存档读进来补上野外记忆；正在外面的老存档，带出去的柴捆按根放进背包，身体满，人在林口。
- **v0.4 里照搬的**：资源点按天数和季节恢复；独一份的拿一件少一件；20 格计数；满了东西留在原地；燃油、罐头到家里上限就不拿；回家和昏倒同一处收账、素材不丢；必须走回林口才能回家；面板暂停、户外临时专注冻结的测试；真浏览器冒烟的做法。v0.4 的几处小毛病（`visited` 只增不读、柴捆和捡的柴分开占格、体温浮点、去程不失温回程失温、只有一个命令清 `carry`）都不在了。

**测试**：148 条（原 128 条，加 `tests/wild.test.ts` 19 条和长跑 1 条）。`npm run typecheck` 通过。不出门的 `npm run longrun` 和改动前逐行相同（只差用时）。真浏览器冒烟 `node tools/wild-smoke.mjs` 通过：键盘走两格各花 2 分钟；按住方向键一秒连发 30 次走了 5 步；鼠标按住采集按钮跨过一次心跳重画再松开，采集照样生效；走回林口回家，柴按根入库。

## 2. 02 没写死、我先选了一种做的（等用户定）

数都在 `IMPL.wild`，改一个数不用动规则。

| | 我的做法 | 为什么，代价 |
|---|---|---|
| W1 每个动作花多久 | 走一格 2 分钟；歇一会儿 10 分钟；吃一份干粮 10 分钟；生火 10 分钟、给烧着的火添柴 3 分钟；采：枯枝 45 分钟、松子浆果 25 分钟、工棚的东西一次 15 分钟 | 采完松林能采的、走完来回，一趟大约 6 个游戏小时，冬天 9 点出门下午三点多回家，「从容」。代价见第 4 节 |
| W2 原地等 | 没有单独的「等」，**「歇一会儿」就是等**：10 分钟，回体力，在篝火边也回体温 | 多一个按钮没有用处；按动作走以后，想等天亮或等火烤暖，就是歇 |
| W3 体温 | 每分钟掉：冬 好天 15、一般 25、大雪冻雨 50；春秋 10 / 18 / 40；夏 4 / 10 / 30（满值 10000）。天黑以后每分钟再多掉 20。在点着的篝火旁边（同格或相邻）每分钟回 150。体温见底以后每分钟掉 100 生命 | 对着交接里的目标调的：冬天好天从容走一趟（6 个小时上下）不用生火，回到家还剩四成多；一般的天气 6 个半小时见底，待久了要生一次火；大雪冻雨 3 个多小时见底，要带柴。夜里更冷：冬天好天天黑后掉得比一般的天气白天还快。夏天好天几乎不冷 |
| W4 体力 | 每分钟耗：走 25、路上 20、采 30、生火 20；歇每分钟回 150；吃一份干粮回 3000（饭点在外面自动吃的那份也回）。**体力到 0 会昏倒**，到 0 之前提醒一次 | 02 第 9.7 节写「体力见底会昏倒」，v0.4 里走不到 0。现在走得到，但有提醒，歇一次回 1500，带两份干粮的一趟正常玩碰不到。也可以改 02 的字，让体力见底只是走不动、不昏倒——我倾向保留，提醒在前，代价很小 |
| W5 干粮 | 可以随时吃一份（「吃一份干粮」），回体力；饭点在外面照旧自动吃一份（D6 暂行），也回体力。没带干粮的饭点仍不算缺餐 | 02 第 9.4 节写吃干粮能恢复体力。D6 我建议**就按现在的定下来**：没带干粮的后果是体力没补上，已经是自然的代价，不必再记缺餐 |
| W6 篝火 | **固定的生火点**（03 第 5.1 节「每个区域有一到两处生火点」），松林两处：林口附近一处、工棚旁一处。要一捆柴（3 根，背包里带的和捡的都算），烧 90 分钟，再添一捆接着烧 | 哪里都能生会让体温的压力消失，生火点就是地图上的「安全的地方」 |
| W7 独一份的东西怎么记 | 记「拿走了几件」，还剩几件 = 03 的账 − 拿走的 | 交接里写「记还剩几件」，意思是按数量不按有没有拿过。记拿走的数，以后 03 补齐数量（比如工棚加种子）老存档也拿得到；记剩下的数就拿不到 |
| W8 一次拿多少 | 枯枝一次 3 根，松子浆果一次 1 份（都按天数恢复：枯枝 3 天，松子浆果 5 天）；工棚的东西一次最多拿一格的量（5 件），木料要拿两次 | 枯枝 45 分钟 3 根，合每小时 4 根，比他在屋边备柴（4 小时 20 根，每小时 5 根）少，路上的时间还不算——守住 02 第 9.3 节「野外弄柴粮不比屋边划算」 |
| W9 满了怎么办 | 会恢复的东西装不下整份就不采；工棚的东西装得下几件拿几件，剩下的留着。有上限的（柴、食材、燃油、罐头）按「家里的 + 背包里的」算，到上限就不拿，说一句「家里的 X 放满了，先留在这里」 | v0.4 只对燃油、罐头这样做，食材和柴是回家时截掉。统一成拿之前就说，不悄悄丢 |
| W10 昏倒丢什么 | 柴、干粮、食材按 `collapseLossRatio`（一半）丢；燃油、罐头、素材全留 | 02 第 9.7 节「普通物资丢一部分；素材、藏品不丢」。燃油和罐头是独一份的，丢了就再也没有，算进不丢的一边 |
| W11 下午昏倒 | 和午夜一样：在床上醒来，已经是第二天早上，炉子是凉的，先生火。这天剩下的饭不算缺餐 | 02 第 9.7 节没区分几点昏倒 |
| W12 回家 | 只能站在林口那一格回家；点「从林口回家」之前要自己走到林口（点格子会自动走过去，路照样花时间） | 「必须走回林口」照搬 v0.4 |
| W13 冷了、累了的提醒 | 体温掉到三成、体力掉到两成各提一句，回到这一线以上再掉下来会再提。和返家提示一样不抢焦点、不要确认 | 02 第 14.5 条的精神 |

**长跑**（`npm run longrun -- --case outings`，40 个种子 × 8 年，照他自己的习惯做项目，每 3 天如果是好天或一般的天气就带他去一趟松林，带 2 份干粮 1 捆柴，下午两点半以后回家）：

| | 不出门（natural） | 每 3 天出门 |
|---|---|---|
| 丰足 / 正常 / 俭 | 51.3% / 48.6% / 0.1% | 55.5% / 44.4% / 0.0% |
| 缺餐、无火 | 0、0 | 0、0 |
| 有活计的日子 | 40% | 35% |
| 他自己备的柴（每年） | 291 根 | 243 根 |
| 每年出门 | — | 8.4 趟，昏倒 0 次 |
| 每年从野外带回 | — | 枯枝 50 根、食材 7 份；8 年里工棚的东西陆续拿完 |

出门让家里稍宽裕一点、他少干一点活，家不靠它（不出门的俭也只有 0.1%）。这条策略回家早，几乎不用生火；冷和累的压力要等实机玩一趟才知道合不合适。

## 4. 要留意的

- **出门会变成快进键**，这是选「按动作走」时就知道的代价：去松林一趟在游戏里约 6 小时，现实里点得快的话一两分钟就过去了，家里的炉火、饭点、天色也跟着过去。按住方向键一步隔 200 毫秒，只挡得住「一秒跳半天」，挡不住连着点「歇一会儿」。要不要给「歇」加一点现实里的停顿（比如歇的时候有一两秒的动画，期间不接下一个动作），等用户实际玩一趟再说。
- 「户外临时专注」照旧冻结，进去出来都不走时间。
- 动物（兔、野猪、狼）、火把、提灯、大背包还没做。夜里「看不清、有狼」现在只有「更冷」。
- 给 00 登记的（由统筹窗口并）：野外按动作走已实现；W1–W13 是暂行做法；D6 建议按现状定；02 的改动草案等用户点头。
