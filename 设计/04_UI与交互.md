# 04｜UI 与交互

> 状态：**草案 v0.1**（2026-11-12）。3 个待定项（U1–U3）在第 12 节。
>
> 标注：【已确认】用户明确选过或前几步已定稿；【沿用 Demo】旧 Demo 已有；【新提议】本轮新提的方案；【待定】要用户选。
>
> 这一步定界面的结构、布局和操作。颜色、字体、像素风格、图标画法留到 05 美术与音频。线框图只表示位置关系，不是最终样子。

## 0. 原则

1. **信息跟着意图出现。** 专注时画面上几乎没有界面；回访时一眼看到状态；出门时才有完整的生存信息。【已确认】
2. **不抢焦点。** 任何提示都不弹窗、不遮画面中央、不抢键盘输入。【已确认】
3. **你说意图，他做过程。** 点一下家具，他自己走过去做完，不用拖材料、点一串菜单。【已确认】
4. **一眼看懂。** 回访的那几秒要能回答三个问题：他在干嘛，家里怎么样，我今天专注了多少。【新提议】
5. **画面本身就是界面。** 柴堆的高度、火的大小、桌上摊着的书，本身就在显示状态，不再重复做成数字条。【已确认方向】

## 1. 整体结构

### 1.1 两个视图【已确认 R2】

| 视图 | 看到什么 | 什么时候 |
|---|---|---|
| **木屋** | 住所。专注和陪伴都在这里 | 默认。他人在野外时这里是空屋，炉里留着余火 |
| **户外** | 游戏人物所在的地方 | 他在家时，切到户外就是出门；他在野外时，切过去接着玩 |

画面右上角有一个切换钮。

### 1.2 三种窗口形态【小窗和菜单栏已确认，Web 阶段只做前两种】

| 形态 | 用途 | 有什么 |
|---|---|---|
| 完整窗口 | 回访、安排、翻手记、出门游玩 | 全部功能 |
| 小窗 | 专注时放在屏幕一角 | 只有木屋画面和计时，置顶，不抢焦点 |
| 菜单栏 | 收起来只听声音 | 菜单栏图标显示计时；点开是一个小面板 |

户外视图只在完整窗口里有。小窗里切到户外，会先变回完整窗口。

- 侧栏放专注工具：计时、任务清单、今天的统计。可以收起。

### 2.2 一眼信息【新提议】

| 位置 | 内容 |
|---|---|
| 左上 | 第几天、季节、天气。自选了场景时，旁边有一个小标记显示真实天气 |
| 右上 | 今天的份：9 个小点，得到的亮起。不显示数字，不显示「还差几个」 |
| 左下 | 他在做什么，一行字，例如「在读《观测员手册》」「在院子里劈柴」「睡着了」 |
| 画面里 | 柴堆高度、粮架、火势、桌上的慢事 |

点左下那行字，展开一张小卡片：

```
┌────────────────────────────┐
│ 在读《观测员手册》  5 / 8 格 │
│ 柴 宽裕   粮 丰足          │
│ 意向：随他  ▾              │
│ 还有 2 份没做              │
└────────────────────────────┘
```

柴和粮只显示档位（清俭、宽裕、丰足），不显示具体数字。想看数字，点储物架或柴堆。

### 2.3 点家具【沿用 Demo】

- 鼠标移到家具上有淡淡的描边。点一下，旁边出现一两个选项，例如壁炉：「添柴」「看看」。
- 选了以后他自己走过去做。最多排 3 件，左下角显示队列，可以取消。
- 点床：「小睡一会儿」「睡到明天」。
- 点门：打开行囊面板（见第 5 节）。
- 专注进行中也可以点，不会暂停专注。

### 2.4 意向【新提议】

在一眼信息的小卡片里，一个下拉：随他、多备柴、多备粮、专心做某件慢事、菜地种什么。选了就一直生效，直到改掉。

### 2.5 镜头【四个视角已确认，院子和长卷是新提议】

| 镜头 | 看到什么 |
|---|---|
| 全景 | 横向长卷：左边木屋剖面，右边院子。他不管在屋里还是院里都在画面内 |
| 雪窗 | 窗和窗外 |
| 书桌 | 书桌和书架 |
| 壁炉 | 壁炉和扶手椅 |
| 院子 | 劈柴墩、菜地、暖棚 |

- 默认是全景。因为他每天上午在院子里干活，全景把屋里和院子画在一起，画面里始终有人。
- 特写镜头是你自己选的。他不在这个镜头里时怎么办，见 U2。
- 切镜头只改画面，不影响他。镜头选择会记住。

### 2.6 场景面板【已确认可自选，面板新提议】

```
┌─────────────────────────────┐
│ ● 跟随世界                  │
│ ○ 自选   天气 [小雪 ▾]      │
│ ─────────────────────────── │
│ □ 世界暂停（纯氛围）        │
│     季节 [冬 ▾] 时段 [夜 ▾] │
└─────────────────────────────┘
```

- 「自选」只换天气的画面和声音，世界照常走。
- 勾上「世界暂停」就是纯氛围：季节、天气、时段都能选，储备不消耗，专注照常计时。

### 2.7 声音面板【三层已确认，其余新提议】

每层一个音量滑块：风雪和天气、炉火、屋里的生活声、电台（修好以后才有）。两个预设：柔和、真实。一个总静音。

### 2.8 他不在家时

木屋视图照常可用：空屋，余火，声音照常，可以专注。左下那行字显示「出远门了，在伐木场的猎人小屋」。点家具没有反应。

## 3. 专注工具

### 3.1 开始专注

底栏的计时区，一次点击就能开始，沿用上次的时长和任务。点时长或任务名可以改：

```
┌──────────────────────────────┐
│ 时长  25/5  45/10  50/10     │
│       自定义   正向计时      │
│ 任务  学习 Java         ▾    │
│ □ 结束后自动接下一轮         │
│            [ 开始 ]          │
└──────────────────────────────┘
```

### 3.2 进行中

- 显示剩余时间（正向计时显示已过时间）、任务名、暂停和结束。
- 结束时间到：一声柔和的提示音，计时区变成「休息 5:00」或「完成」。不弹窗。
- 休息结束：再一声提示。没勾自动接下一轮，就停在那里等你。
- 得到一份：右上的小点亮一个，没有声音。
- 满 9 份：左下那行字换成「今天的份满了」，停留一会儿。

### 3.3 任务【沿用 Demo】

侧栏里的清单：名称、类别、累计时间、勾选完成。新建只要输一个名字，类别默认沿用上一个。完成的任务折叠在下面。

### 3.4 统计

在手记的「专注」一栏里（见第 7 节）。侧栏底部只有一行今天的数字。

## 4. 小窗与菜单栏【已确认两种都支持，细节新提议】

### 4.1 小窗

```
┌────────────────────────┐
│                        │
│       木屋画面         │
│                        │
│ 18:42            ● ● ○ │
└────────────────────────┘
```

- 16:9，三档大小，可拖到屏幕任意位置。置顶可开关。
- 平时只有画面和左下的计时（见 U1）。鼠标移上去才出现：暂停、结束、镜头、声音、展开成完整窗口。
- 单击不会夺走你正在用的应用的键盘焦点。
- 小窗的默认镜头单独记，不跟完整窗口共用。小窗里全景的人会很小，所以默认用特写。

### 4.2 菜单栏

- 图标旁边显示剩余时间。
- 点开是一个小面板：开始、暂停、结束、任务、今天的份、音量、打开小窗、打开完整窗口。
- 收到菜单栏时停止绘制画面，声音和世界照常。

Web 阶段没有菜单栏，小窗用一个可以单独打开的紧凑页面来模拟。

## 6. 户外视图

### 6.1 画面上的东西【方向已确认，布局新提议】

```
┌──────────────────────────────────────────────────────────┐
│ 体温 ▮▮▮▮▯                              10:40 小雪 [地图] │
│ 体力 ▮▮▮▯▯                                               │
│ 生命 ▮▮▮▮▮                                               │
│                                                          │
│                     俯视地图画面                          │
│                                                          │
│                                                          │
│ [斧] [弓] [矛] │ [干粮 2] [柴捆 1] [火把]     [背包] [木屋] │
└──────────────────────────────────────────────────────────┘
```

- 三项身体状态在左上。状态好的时候变淡，掉到一半以下才醒目。
- 右上是游戏里的钟点、天气、地图。
- 底栏左边是武器，中间是随手用的补给，右边是背包和回木屋视图的按钮。
- 天色、风雪、呼出的白气本身也在显示时间和冷暖。

### 6.2 操作【沿用 Demo】

| 操作 | 作用 |
|---|---|
| WASD | 走路 |
| 点地面 | 走过去 |
| 点资源点 | 走过去采 |
| 点掉落物 | 走过去捡 |
| 点动物 | 用当前武器，自动靠近或瞄准 |
| 点生火点、营地点、落脚点、出口 | 走过去，出现选项 |
| Esc，或按任意方向键 | 停下当前的动作 |

点击时先看有没有点中可交互的东西，没有才当作走路。

### 6.3 采集

走到跟前，头顶一个小进度圈，采完东西飞进背包，背包按钮跳一下数字。背包满了，他会说一句「装不下了」。

### 6.4 战斗【规则已定，界面新提议】

- 点中的目标脚下有一个圈。底栏中间临时换成两个大按钮：「停手」「撤退」。
- 读过《霜兽观察笔记》的，目标旁边有一行小字提示习性，例如「怕火」「别站在它正面」。
- 点火把：他举起火把，周围一圈暖光，圈里霜兽不进来。火把剩余时间显示在按钮上。
- 生命掉到三分之一以下，画面边缘发暗，提示可以撤退。

### 6.5 生火、过夜、回家

走到生火点、营地点或落脚点，出现选项卡：

```
┌────────────────────────────┐
│ 一堆熄灭的小火堆           │
│ 这里可以露营。             │
│ ▸ 生火歇一会儿（1 捆柴）   │
│ ▸ 搭帐篷过夜（2 捆柴 1 干粮）│
│ ▸ 启程回家（约 3 小时）    │
└────────────────────────────┘
```

不够的补给标成灰色，并写明差什么。

### 6.6 路上的事

穿过出口时，画面暗下来，出现一张卡片：一两句话，一两个选择，每个选择下面写明代价。选完画面亮起，到了下一个区域。

```
┌──────────────────────────────────┐
│ 风雪突然大了，前面的路看不清。   │
│ ▸ 找个背风的地方生火等一阵       │
│     用 1 捆柴，多花半小时        │
│ ▸ 硬着头皮走                     │
│     体温大降                     │
└──────────────────────────────────┘
```

### 6.7 地图【已确认方向】

手绘风格。只画出去过的区域和知道的路；阻碍着的路画成虚线，旁边写着缺什么（「雪太深」「不知道路」）。落脚点、营地点、生火点发现后才标出来。可以自己加标记。没有任务标记和问号。

### 6.8 背包

20 格的格子。点一样东西：用掉（干粮）、丢下、看说明。独一份的东西有一个小角标，丢不掉。

### 6.9 昏倒

画面慢慢变白，一行字：「……醒来的时候，已经在家里了。」然后回到木屋视图，第二天早上。手记里记下丢了什么。

## 7. 时光手记【内容已定，版式新提议】

翻开是一本日志本，左边书签是六栏：

| 栏 | 内容 |
|---|---|
| 日子 | 按天翻的日志，每天一条小结和当天的事 |
| 专注 | 今天、本周、按类别、按任务的统计；每次专注的记录；三条成就线走到哪了 |
| 慢事 | 进行中的（进度条按格画）、做完的、每件的摘抄 |
| 收藏 | 藏品和照片；这里可以换摆在屋里的是哪几件 |
| 见闻 | 去过的地方、风景点、动物和霜兽的图鉴、窗外的小事、拼图 |
| 这一年 | 每过一年多一页 |

- 只在你点「手记」时打开，从不自己弹出。
- 有新内容时，「手记」按钮旁边有一个小点，不闪、不计数。
- 拼图在「见闻」里是一页八个空位，找到一块填上一块。全部填上后，这页变成一篇连起来的记述。

## 8. 设置

- 声音：各层音量、预设、提示音开关。
- 画面：气泡开关、减少动态效果、控件淡出的时间。
- 专注：默认时长、自动接下一轮、换日时间（默认凌晨 4 点）。
- 数据：导出、导入、重置。专注记录可以单独导出。
- 名字：给他起名或改名。

## 9. 第一次打开【新提议】

1. 一段十几秒的开场：雪里走来一个人，推开观测站的门，生起火。
2. 「要给这个人起个名字吗？」可以跳过。
3. 进入木屋视图。底栏的计时区亮一下，一行字：「开始专注，或者就这样开着。」
4. 之后不再有教程。第一次点家具、第一次得份、第一次出门时，各有一行字的提示，出现一次。

## 11. 什么时候出声、出字

| 事 | 出声 | 出字 |
|---|---|---|
| 专注结束、休息结束 | 一声柔和的提示音，可关 | 计时区变化 |
| 得到一份 | 无 | 右上亮一个点 |
| 份满了 | 无 | 左下一行字 |
| 慢事做完 | 无 | 手记按钮旁一个点；他会有一个小动作 |
| 到一档成就 | 无 | 手记按钮旁一个点 |
| 过了一天 | 无 | 左上的天数变了 |
| 窗外的小事 | 自然的声音 | 无 |
| 他的气泡 | 无 | 一行小字，几秒消失，可关 |
| 出门遇到危险 | 环境声和动物的声音 | 身体状态变醒目 |

专注进行时，除了第一行，其他都不出声。

## 12. 待定项

**U1 专注时计时数字怎么显示**

- a. 一直显示，小而淡，放在画面一角（推荐）。专注工具最常被看的就是还剩多久，抬眼就该看到。设置里可以改成隐藏。
- b. 默认不显示数字，只有一条很细的进度线；鼠标移上去才显示时间。画面更干净，但想看时间要动一下鼠标。

**U2 你选了特写镜头，而他不在这个镜头里**

- a. 就是空镜：没有人的书桌、壁炉、窗（推荐）。安静，不会有突然的画面切换打扰你。
- b. 镜头自动跟过去，他到哪就切到哪。画面里一直有人，但专注时切镜头会吸引注意力。

**U3 完整窗口默认什么样**

- a. 默认画面全幅，专注工具的侧栏收起，一键展开（推荐）。
- b. 默认侧栏展开，任务清单和计时一直在右边。更像一个专注工具，但画面小一些。
