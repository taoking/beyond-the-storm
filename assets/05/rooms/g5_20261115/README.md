# 四间木屋：可分层的 2560×1440 游戏场景基础版（2026-11-15）

这一版是真实的 **RGBA 游戏用分层资产**，不是将图片作为 Markdown 截图展示。四间完整 16:9；炉间与卧室采用更低的窗下沿，近落地玻璃；仅炉间有柴炉。原始图从已获用户认可的四间无人物画面导出。

## 文件
每间目录都有：`interior_rgba.webp`（玻璃局部透明）、`outside_winter_day_rgba.webp` / `outside_winter_night_rgba.webp`（单独窗景）、`glass_mask.png`、`night_ambient.webp`、`day_preview.webp`。GitHub 采用具有透明通道的 WebP 格式加速加载，原始 PNG 作为输入可按构建脚本复现。

运行 `python3 validate.py` 核对完整性。用浏览器打开 `preview.html` 可以切四间和昼夜，浏览器实际使用独立分层图片而非单张画面。此处为静态画面验证，真正接入 06 Snapshot 仍需 Claude。
